# Fotos de productos (entrada)

Aquí el equipo de Olivo deja las fotos **sin procesar**, una subcarpeta por categoría. Claude Code las recorta, optimiza y copia a `public/images/products/<categoria>/<SKU>.jpg`, y luego corre `npm run sync-images`.

Formato, nombres y cómo exportar desde Canva: `docs/guia-fotos-productos.md`.
